СОЗДАЙ СЕБЯ — бесплатная PWA-версия для iPhone

ПУБЛИКАЦИЯ НА GITHUB PAGES:
1. Открой репозиторий https://github.com/arslan558866-svg/ArsT
2. Загрузить содержимое этой папки в корень репозитория: index.html, manifest.webmanifest, sw.js, .nojekyll и папку assets.
3. Commit changes.
4. В GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
5. Branch: main; Folder: /(root); Save.
6. Подожди завершения публикации. Адрес обычно будет:
   https://arslan558866-svg.github.io/ArsT/

УСТАНОВКА НА IPHONE:
1. Открой опубликованный адрес в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Подтверди добавление.

ВАЖНО:
- Это бесплатная веб-версия/PWA, не нативное приложение App Store.
- Face ID как отдельная блокировка пока не реализован в PWA.
- Записи сохраняются в локальном хранилище браузера этого устройства. Экспортируй резервную копию JSON.
- Для синхронизации iCloud потребуется отдельная разработка и настройка.
- Визуальная анимация медведя — декоративная. Она не является инструкцией по технике упражнений.
